# マネタイズ戦略：トライアル・フリーミアムモデル

## 概要

「小学コレプログラミング」は**フリーミアムモデル**を採用しています。ユーザーは無料コンテンツを楽しむか、**2週間の無料トライアル**でプレミアム機能を試した後、プレミアム購読に移行できます。

### 売上ストリーム
1. **プレミアム購読** - 月額制（主要な収益源）
2. **広告収益** - バナー広告、インタースティシャル広告（月500円相当の見積もり）
3. **一時購入** - 今後の実装予定（単発購入オプション）

---

## コンテンツ戦略

### 無料コンテンツ
- **対象**: 初級ステージ（約40%）
- **内容**: 
  - 基本的なプログラミング概念
  - ビジュアルプログラミング入門
  - 簡単なクイズ

### プレミアムコンテンツ
- **対象**: 中級・上級ステージ（約60%）
- **内容**:
  - 応用的なプログラミング概念
  - 複雑なビジュアルプログラミング
  - 高度なクイズ問題
  - 週次チャレンジ（将来実装）
  - AI コーチング機能

### トライアル期間中（2週間）
- **アクセス**: すべてのプレミアムコンテンツ利用可能
- **広告**: 表示なし
- **推奨使用**: ユーザーに十分にサービスを体験させ、購読の価値を理解させる

## ユーザーフロー

```
ユーザー登録
    ↓
アプリ起動
    ├→ トライアル開始提案
    │   ↓
    ├→ トライアルスキップ
    │   ↓ （広告表示開始）
    │   有料コンテンツへのアクセス要求
    │   ↓
    │   「ロック解除」画面
    │   ├→ トライアル開始
    │   └→ プレミアム購読
    │
    └→ トライアル開始
        ↓
        [2週間] すべてのコンテンツ利用可能
        ↓
        トライアル終了
        ├→ プレミアム購読継続
        └→ 無料ユーザーに戻る
           ↓（広告表示開始）
           定期的な購読促進通知
```

---

## トライアル管理

### ユーザーのライフサイクル

#### Phase 1: 新規ユーザー（トライアルなし）
```
状態: has_used_trial = false
コンテンツアクセス: 無料のみ
広告: 表示
アクション: トライアル開始ボタンを強調
```

#### Phase 2: トライアル中（14日間）
```
状態: is_trial_active = true
コンテンツアクセス: すべて
広告: 非表示
UI: 「トライアル残り X 日」バナー表示
```

#### Phase 3: トライアル終了（期限切れ）
```
状態: is_trial_active = false, has_used_trial = true
コンテンツアクセス: 無料のみ
広告: 表示（強化）
UI: 「プレミアム購読で続ける」ダイアログ
```

#### Phase 4: プレミアム購読中
```
状態: is_premium_subscriber = true
コンテンツアクセス: すべて
広告: 非表示
UI: 「プレミアム購読中」バッジ表示
```

## 実装技術

### データ管理
- **保存先**: SharedPreferences（ローカル）
- **同期**: 将来的に Firebase Firestore で同期化予定

### プロバイダー構成
```
subscriptionProvider: トライアル状態管理
├── isTrialActiveProvider: トライアル中フラグ
├── canAccessPremiumProvider: 有料コンテンツアクセス可否
├── shouldShowAdsProvider: 広告表示判定
├── trialDaysRemainingProvider: 残り日数
└── trialProgressProvider: 進捗（0-1）
```

### ビジネスロジック
```
MonetizationService
├── canAccessChallenge(): チャレンジアクセス判定
├── getChallengeLockReason(): ロック理由を取得
├── shouldDisplayAds(): 広告表示判定
└── getStatistics(): コンテンツ統計
```

## 規制・ポリシー

### App Store/Google Play
- ✅ 無料アプリ → プレミアム機能説明必須
- ✅ トライアル期間：14日（標準）
- ✅ キャンセル方法：設定 > サブスクリプション で明示
- ✅ 自動更新：明確な同意が必須

### 広告ポリシー
- Google Mobile Ads ポリシー準守
- 子ども向けアプリのため：
  - ターゲティング広告なし
  - 過度な広告頻度の制限
  - 不適切な広告フィルタリング
