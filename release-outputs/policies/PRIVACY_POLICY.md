# プライバシーポリシー / Privacy Policy
## 小学コレ！プログラミング

**最終更新日 / Last Updated**: 2026-06-08

---

## 1. 収集するデータ / Data We Collect

本アプリ（小学コレ！プログラミング）は、以下のデータのみを収集・利用します。

### ローカルデータ（端末内に保存）
- 学習進捗（クリア済みステージ・獲得スター数）
- コイン残高・購入済みショップアイテム
- アプリ設定（通知時刻・サウンド・テーマ）
- 苦手問題履歴・お気に入りステージ

### AIコーチング機能（Anthropic API）
- AIコーチングボタンを押した際、**問題のコンテキスト（学習中の概念・回答状況）** を Anthropic 社の API に送信します
- 個人を特定する情報（氏名・メールアドレス等）は送信しません
- Anthropic のプライバシーポリシー: https://www.anthropic.com/privacy

### 収集しないデータ
- 氏名・メールアドレス・電話番号等の個人情報
- 位置情報
- カメラ・マイクのデータ
- 連絡先

---

## 2. データの利用目的 / How We Use Data

1. 学習進捗の保存・表示
2. AIコーチング機能の提供
3. プッシュ通知（学習リマインダー）の送信
4. アプリ機能の改善

---

## 3. データの保存場所 / Data Storage

- 学習データはすべて**お使いの端末内**（SharedPreferences）に保存されます
- クラウドサーバーへの保存は行いません
- アプリをアンインストールするとすべてのデータが削除されます

---

## 4. 第三者への提供 / Data Sharing

- ユーザーデータを販売・共有することは**一切ありません**
- AIコーチング機能使用時のみ、Anthropic 社の API を利用します（上記参照）
- 課金機能（プレミアムプラン）は Google Play の課金システムを使用します

---

## 5. 対象年齢 / Target Age

本アプリは小学生を主な対象としています。13歳未満のお子様の個人情報は収集しません。
